# 🐀 Pied Piper

Proyecto personal para entender cómo funciona la compresión de datos,
desde los conceptos básicos hasta algoritmos más avanzados.

Inspirado en el Pied Piper de *Silicon Valley*.

## Objetivo

Construir un compresor desde cero y entender el porqué de cada parte,
no solo hacer que funcione.

## Conceptos

- Bits y bytes
- Redundancia
- Entropía
- Huffman
- LZ
- Compresión sin pérdida
- Compresión de imágenes
- Compresión de video
